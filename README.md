# StudyBuddy

An installable study app (PWA) for school students.

Features: calendar, Pomodoro focus timer, calculator, notes generated from an
uploaded chapter (PDF / Word / text / photo), an AI doubts bot (Sarvam or OpenAI
key, or offline notes search), syllabus tracking, daily tasks and study stats.

Everything is stored locally in your browser (localStorage) and works offline
after the first load.

## Install on your phone
Open the site in Chrome (Android) or Safari (iOS), then use
"Add to Home screen" / "Install app".
